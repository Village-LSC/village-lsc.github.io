# Руководство по добавлению шаблонов в калькулятор

Все шаблоны хранятся в файле:
`src/data/templates.json`

Вы можете добавлять сколько угодно своих шаблонов, изменять размеры, цены, категории и указывать ссылки на ваши собственные рисунки/картинки!

---

## 📋 Структура объекта шаблона

Каждый шаблон в массиве `"templates"` описывается следующим JSON-объектом:

```json
{
  "id": "my_new_template",
  "titleRu": "Оружие Героев",
  "titleEn": "Hero Weapons",
  "image": "/templates/my_weapon.png",
  "categoryId": "1",
  "badgeRu": "Кат. 1 • Оружие",
  "badgeEn": "Cat. 1 • Weapons",
  "descRu": "Сет легендарного оружия с эффектами свечения для RPG-игры.",
  "descEn": "Legendary weapons set with glow effects for RPG game.",
  "defaultWidth": 32,
  "defaultHeight": 32,
  "approxPriceRangeRu": "240 – 380 ₽ / шт.",
  "approxPriceRangeEn": "240 – 380 ₽ / pcs",
  "approxBasePrice": 310,
  "defaultCountOrig": 4,
  "defaultCountVar": 0,
  "hasAnimation": false,
  "defaultDuration": 1.0,
  "defaultQuality": "optimal",
  "defaultAnimComplexity": "simple",
  "defaultDetailLevel": "moderate",
  "defaultTaskDescRu": "4 вида мечей: огненный клинок, ледяная рапира, рунический меч, теневой кинжал.",

```

## 🏷️ Категории (`categoryId`):
Значение поля `categoryId` **СТРОГО совпадает с обычными базовыми категориями калькулятора**, благодаря чему стоимость и формулы автоматически рассчитываются по тарифам выбранной категории:

- `"1"` — **Предметы, тайлы, окружение** *(оружие, броня, зелья, блоки уровней, пропсы, декорации)*
- `"2"` — **Текстурирование моделей** *(развертки и пиксельные текстуры для low-poly 3D моделей в Blockbench)*
- `"3"` — **UI: базовые элементы** *(кнопки, иконки навыков, баффы, HP/MP индикаторы, слоты)*
- `"4"` — **UI: окна, шрифты, статичные фоны** *(инвентари, окна крафта, панели настроек, пиксельные шрифты)*
- `"5"` — **UI: сложные фоны, логотипы** *(детализированные художественные панорамы, меню, титульные логотипы)*
- `"6"` — **Портреты \ спрайты диалогов** *(аватары NPC, лица и плечевой пояс для диалоговых окон)*
- `"7"` — **Minecraft скины** *(скины игроков и мобов 64×64 или HD 128×128)*
- `"8"` — **Иное (нестандартные задачи)** *(спецэффекты, игровые картины, анимации существ, кастомные концепты)*

## 🎨 Поле `image` (Картинка шаблона):
- **Серый квадрат (пока нет картинки):** оставьте пустую строку `""`. В карточке отобразится стильный серый квадрат-плейсхолдер с сеткой и меткой `[ Картинка ]`.
- **Своя картинка:**
  1. Положите файл картинки (например, `my_sword.png`) в папку `public/templates/` вашего проекта.
  2. В поле `image` укажите путь: `"/templates/my_sword.png"`.
  3. Также можно указывать внешние интернет-ссылки: `"https://example.com/art.png"`.

---

## 📏 Размеры (`defaultWidth`, `defaultHeight`):
Укажите любой нужный размер в пикселях: `16`, `24`, `32`, `48`, `64`, `128` и т.д.

---

## ⭐ Качество по умолчанию (`defaultQuality`):
- `"optimal"` — Базовое / оптимальное качество (чистые пиксельные формы)
- `"medium"` — Умеренное качество (улучшенные текстуры и светотени)
- `"best"` — Детализированное качество (высокая детализация)
